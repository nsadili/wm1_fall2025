# Frontend Course – Weekly Class Notes

This repository hosts weekly class notes for the **Web and Mobile 1 course**.  
Each CRN has its own dedicated branch to keep the materials organized.

## Branches

- **`20210`** → Contains notes for CRN **20210**
- **`20211`** → Contains notes for CRN **20211**

## How to Access Notes

1. Select the branch that matches your CRN from the branch dropdown at the top of the repository.
2. Browse through the weekly folders/files to view the class notes.
